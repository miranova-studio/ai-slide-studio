# CLAUDE.md

## Goal

FRAME is a browser-based slide editor. Preserve JSON import/export compatibility, IndexedDB persistence, presentation, and print output when changing the UI.

## Source of truth

- `src/schema/slide-deck.schema.json`: canonical external interchange format
- `docs/course-schema.md` and `docs/examples/course-sample.json`: course hierarchy and external JSON example
- `src/course.ts`: course order, duration calculation, and stable script filenames
- `src/components/CourseOutline.tsx`: section/lecture tree and reordering
- `src/services/courseFiles.ts`: script CSV/ZIP and complete course package
- `src/services/lecturePdf.ts`: per-lecture PDF with embedded Japanese font
- `src/schema/theme.schema.json`: canonical theme format; see `docs/theme-schema.md`
- `themes/*.json`: bundled themes, auto-discovered by Vite
- `src/data/miranova-palettes.json`: bundled palette snapshot, generated by `npm run sync-palettes`
- `src/themes.ts`: theme validation, layout application, palette mapping, and WCAG contrast
- `docs/slide-schema.md`: coordinates, field meanings, and PowerPoint mapping
- `src/types.ts`: TypeScript types matching the schema
- `src/schema/validate.ts`: validation and `schemaVersion` migration dispatch
- `src/services/storage.ts`: IndexedDB access and one-time legacy LocalStorage migration
- `src/services/ai/adapter.ts`: future server-side AI integration boundary; currently mock
- `src/App.tsx`: editor, import/export, and shared slide renderer
- `src/components/ThemePanel.tsx`: theme and palette editing UI
- `src/styles.css`: workspace UI and print CSS

## Current UI and data contract

- The left panel switches between a title outline and thumbnails. The center switches between single-slide, draggable grid, and vertical scroll views. The right panel switches between element editing, per-slide notes, and themes.
- Slide `hidden`, `notes`, `showMaster`, `narration`, and optional audio metadata plus deck `masterElements`, `themeId`, palette, `mode`, and optional `course` are persisted in schema v5. Presentation and print use only `!hidden` slides; editing and JSON export keep every slide. Master elements render behind slide elements and are selectable only in master-edit mode. The view tabs, editing mode, and selected element are transient UI state.
- The header's `マスター編集` button enters master mode, shows a prominent `マスター編集中` banner, and selects the Edit panel. The banner's `通常編集に戻る` button exits. Master mode uses the single-slide view even if the active slide is hidden; grid/scroll view tabs are disabled until exit. In master mode, edit the shared `deck.masterElements`; in normal mode, decorations must remain unselectable. Switching themes replaces the shared master elements with that theme's decorations, so edits to the prior theme's decorations are not retained across theme switches.
- Shapes support `rect`, `roundRect`, `ellipse`, `triangle`, `line`, and `arrow`. Keep the schema enum, TypeScript type, editor picker, renderer, and future PPTX mapping in sync.
- `src/App.tsx` owns in-memory deck undo/redo snapshots; they are never persisted or exported. Route deck edits through `changeDeck`. Pointer move/resize previews update without creating history entries, then commit one snapshot on release. Native contentEditable/input undo takes precedence over deck shortcuts while typing.
- Text editing begins on double-click and commits on blur. Delete/Backspace removes a selected element only outside editable controls. Thumbnail context menu and the right edit panel both toggle slide visibility.
- `migrateDeck` accepts v4, v3, v2, v1, and unversioned decks. New interchange fields must update the schema, types, migration, docs, and example JSON together.
- Business UI colors are defined as `--ui-*` variables in `src/styles.css`. Slide colors come from the deck palette and theme files, not workspace UI colors.

## Course mode and assets

- `mode: "deck" | "course"` is the root discriminator. In course mode, `slides` contains actual slides and `course.sections[].lectures[].slideIds` gives the order. Every slide ID must occur exactly once. Preserve the deck mode path when changing shared UI.
- Each slide has a `narration` string. `course.charactersPerMinute` defaults to 300. Duration uses `audio.durationSeconds` when present, otherwise the narration estimate. These are production estimates, not verified video duration.
- Audio metadata lives in JSON; the Blob lives in the IndexedDB `audio` store. Never put audio bytes or API credentials in the JSON. JSON import/export does not transfer the Blob; the complete course ZIP includes audio but cannot yet be re-imported wholesale.
- Script stems are `S<section>-L<lecture>-<slide>` with 2-digit, one-based ordinals, produced by `slideFileStem` in `src/course.ts`. Bulk audio matching must use that convention after reordering.
- The ZIP exporter creates one PDF per lecture using `pdf-lib`, fontkit, and embedded Noto Sans JP. Keep it lazy-loaded. Verify Japanese by rasterizing a generated PDF after changes; font subsetting previously produced invisible text in Poppler, so do not re-enable it without cross-viewer verification. The ordinary deck PDF path remains browser print CSS.
- App-internal AI generation and TTS are out of scope. External Claude Code output enters through validated course JSON; any future API needs a server-side key.

## 新しいテーマの作り方

1. Copy one file in `themes/` to a new lowercase-hyphenated `<id>.json`. Keep `id` equal to the filename stem; use a distinct ID and display `name`.
2. Set `palette`, Japanese-capable `fonts`, `masterElements` (shape/image), and `title`/`body`/`image` layout boxes. Coordinates use the 13.333 × 7.5 canvas; see `docs/theme-schema.md`.
3. Run `npm run check:themes`, `npm run typecheck`, and `npm run build`. Reload the dev app or rebuild production to pick up the file. Verify text/image content survives a theme switch.

## パレット同期のやり方

Run `npm run sync-palettes` while online, then review the diff and run `npm run build`. The script reads the JSON array following `window.ATLAS_PALETTES =`, validates it, and atomically writes `src/data/miranova-palettes.json`; a failed fetch leaves the prior file untouched. The app never fetches palettes at runtime.

## パレットからテーマを作る手順

Open the Theme tab, filter/search MIRANOVA palettes, click one to preview, and adjust background/main/accent assignments. Enter a name and use the save/export button; the generated theme name includes the palette name and ID. For source control, use the supported-browser directory picker to save into `themes/`, or place the exported `<id>.json` there manually. Run `npm run check:themes` and rebuild. Keep provider credentials on a backend; never place an API key in a theme file or a browser `VITE_` variable.

Check hidden-slide exclusion for presentation and print.
