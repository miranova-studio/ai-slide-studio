# マスター編集の操作性調査（2026-10-28）

## 再現結果

- ブラウザで「マスター編集」を押すとモードに入り、柄を選択できる。
- 選択した柄の塗り色を変更すると、そのスライドと別のスライドに即時反映された。
- テーマを切り替えた後も、新しいテーマの柄を選択できた。
- ただし入口はキャンバス上部の小さなボタンのみで、編集中の状態表示と終了導線が目立たない。
- テーマ切替では `applyThemeToDeck` が `masterElements` を切替先テーマの柄に置き換える。切替前の柄への編集は引き継がれない。

## 原因と修正方針

主因は操作導線・状態表示の分かりにくさ。上部メニューに入口を設け、マスター編集時には明確な状態表示と終了ボタンを設ける。柄の共有反映処理は保持し、8テーマすべてで選択・色変更・移動・削除が全スライドに反映されるか確認する。

## 修正後の確認

- 上部メニューから入り、明確なモード表示と「通常編集に戻る」から終了できる。
- 8テーマすべてで柄を選択し、色・x位置・削除を変更した。変更は2枚目と3枚目に同じ値で表示された。
- ビジネスの柄をドラッグして移動し、別スライドに同じ位置で表示されることを確認した。保存・再読み込み後も位置は保持された。
- エレガントとミニマルの線柄では、枠線色を変更して別スライドに反映されることを確認した。
- 通常編集へ戻るとマスター柄は選択できない。
