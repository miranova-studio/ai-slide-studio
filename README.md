# FRAME — AI Slide Studio

## ダブルクリックで起動（macOS）

Finderで `ai-slide-studio` フォルダを開き、`AI Slide Studio.app` をダブルクリックしてください。ターミナルは開かず、ブラウザに `http://127.0.0.1:4173/` が開きます。起動に失敗した場合はMacのダイアログで理由を表示します。`AI Slide Studio.command` のダブルクリックでも起動できますが、こちらはターミナルが開きます。初回やソースを変更した後は自動でビルドするため、少し時間がかかります。Node.js と npm が必要です。

すでに AI Slide Studio が 4173 番で動いている場合はブラウザを開くだけです。4173 番を別のアプリが使用している場合は、起動せずエラーを表示します。`.app` を Dock に置くには、Finderからそのアイコンを Dock にドラッグしてください。フォルダを移動する場合は Dock に登録し直してください。

外部で作ったスライドJSONを読み込み、ブラウザで編集・保存・PDF出力できるMVPです。左パネルは目次／サムネイル、中央はスライド／一覧／スクロール、右パネルは編集／メモ・修正指示／テーマに切り替えられます。参考動画を確認し、合意した画面構成を反映しています。

## セットアップ

```bash
npm install
npm run dev
```

表示されたURL（通常は `http://localhost:4173`）をブラウザで開きます。

データはブラウザ内のIndexedDBに保存され、次回起動時に再読み込みされます。別ブラウザへの移行にはJSONエクスポートとインポートを使ってください。画像はdata URLとしてJSONに含まれます。スキーマとPowerPoint変換の注意点は [docs/slide-schema.md](docs/slide-schema.md) を参照してください。

現在のJSONはschemaVersion 7です。v6・v5・v4・v3・v2・v1と初期のバージョン番号なしのデータはインポート時・保存データ読込時にv7へ移行します。v6は背景色の個別指定なしとして見た目を保持し、v5以前の透明度は100%になります。メモ・修正指示、非表示状態、マスターの柄、選択パレット、背景画像と透明度、講座の階層と台本もJSONに含まれます。表示タブや複数選択の状態は保存しません。

サムネイルと「一覧」は⌘クリック（WindowsではCtrlクリック）で個別に追加、Shiftクリックで範囲選択できます。「一覧」は1回クリックで選択、ダブルクリックで編集画面を開きます。「スクロール」は全スライドを縦に表示し、切替時に選択中のスライドへ移動します。選択したスライドの背景色・画像・透明度を右パネルで一括変更できます。「テーマの背景色に戻す」は「編集」タブの背景色欄の横にあり、個別の背景色指定がある場合に使えます。「すべてのスライドに適用」は現在の背景を全スライドへコピーします。確認画面で非表示スライドを含めるか選べます。一括変更とスライダー1回の操作は、それぞれ「元に戻す」1回で復元できます。

「マスター編集」で共通の柄を通常要素として追加・移動・色変更・削除できます。変更は全スライドに反映されます。通常編集ではマスター要素を選択できません。「このスライドにマスターの柄を表示」のチェックを外すと、そのスライドだけ柄を隠せます。図形の枠線太さは選択中の要素パネルで0〜20に設定できます。

背景色と図形の塗り色・枠線色は、従来の色のマス目に加え、「アプリ内で色を選ぶ」から選べます。現在のテーマ色、選択中のMIRANOVAパレット色、最近使った色のボタン、または `#RRGGBB` の直接入力を使ってください。最近使った色はブラウザ内に保存されます。色変更は「元に戻す」に対応します。

## テーマとパレット

右の「テーマ」タブで8種類のテーマを切り替えられます。テーマ切替は文字・画像の内容とIDを保持し、位置・フォント・配色・マスターの柄をテーマに合わせて変更します。各テーマは [`themes/`](themes/) に1ファイルずつあり、書式は [docs/theme-schema.md](docs/theme-schema.md) を参照してください。

「MIRANOVAパレットから選ぶ」では3色スウォッチ、名前、カテゴリを表示し、カテゴリ・タグ・用途・名前で絞れます。クリックで即時反映します。背景・メイン・アクセントへの割り当てを変更でき、文字色は背景に対してWCAG 4.5:1以上となる黒／白を選びます。JSON・CSS変数・HEX 3色の貼り付けもできます。パレットの出典は [MIRANOVA 3色パレット](https://miranova-studio.github.io/three-color-palette/) です。

```bash
npm run sync-palettes
```

このコマンドで公開の `palettes-data.js` からJSONだけを抽出し、`src/data/miranova-palettes.json` を更新します。取得・解析に失敗した場合、既存ファイルは保持されます。アプリの実行中に外部アクセスはしません。2026-10-28時点の同梱データは208件です。

現在のテーマ＋選択パレットから新しいテーマを作ると、ブラウザ内に保存し、パレット名・IDを含む名前でJSONを書き出します。対応ブラウザでは「themes/ に保存（フォルダ選択）」からソースの `themes/` を選んで直接保存できます。未対応ブラウザではJSONを手動で `themes/` に配置してください。開発サーバーは再読み込み、配布版は再ビルドで新テーマを自動読込します。テーマJSONのインポート・エクスポートにも対応します。

PDFは右パネルの「PDF / 印刷」を押し、ブラウザの印刷画面で「PDFに保存」を選びます。文字は画像化せずブラウザの印刷エンジンで出力します。

要素はクリックで選択し、ドラッグで移動、四隅のハンドルでサイズ変更できます。テキストはダブルクリックで編集します。編集欄で入力中の Delete/Backspace と Cmd/Ctrl+Z は文字編集に作用し、要素削除やスライド全体の履歴操作には作用しません。編集欄の外では、Mac は Cmd+Z／Cmd+Shift+Z、Windows は Ctrl+Z／Ctrl+Y で元に戻す／やり直しができます。履歴はメモリ上のみで、JSONには含まれません。

非表示スライドをPDFから除外する手順：

1. 左の「サムネイル」タブで対象を右クリックし「スライドを非表示」を選ぶ（または右の「編集」パネルで「スライドを非表示」を押す）。目の印と薄い表示を確認する。
2. 右パネルの「PDF / 印刷」を押す。
3. 印刷画面のページ数を確認し、「PDFに保存」を選ぶ。復元は同じ場所の「非表示を解除」を使う。

## 講座モードの使い方と出力

上部の「講座モード」を選ぶと、既存スライドを1セクション・1レクチャーに保持したまま講座へ移行します。左の目次でセクション・レクチャーを追加・改名・削除・ドラッグ並び替えし、各レクチャーのスライドを従来のエディタで編集できます。「講座情報を編集」からタイトル、対象者、学習目標、前提知識、説明文、話速を設定します。右の「台本」タブでスライドごとのナレーションと音声を扱います。台本の時間は日本語300字/分（変更可）による制作目安で、音声があれば実長を優先します。動画の長さやUdemy要件への適合を保証する値ではありません。

講座JSONの外部生成とインポートは [docs/course-schema.md](docs/course-schema.md) と [サンプル](docs/examples/course-sample.json) を参照してください。音声本体はブラウザのIndexedDBに別保存され、JSON単体には含まれません。別環境へ音声も渡す場合は「講座一式ZIP」を使用してください。ただしZIPからの一括再インポートは未実装です。台本は `S01-L02-03.txt`（セクション1・レクチャー2・スライド3）のように命名され、同名のmp3/wav/m4aを一括選択すると自動で割り当てます。未割当ファイルは画面に表示されます。台本ZIPには一覧CSVが含まれ、CSVだけの出力ボタンもあります。

講座一式ZIPには `course.json`、一覧CSV、講座説明テキスト、セクション／レクチャー順のフォルダに台本・音声・`slides.pdf` が入ります。各PDFは日本語対応フォントを埋め込んだテキスト・図形ベースです。フォントは `@expo-google-fonts/noto-sans-jp` のNoto Sans JPを使用します。枚数が多い講座はPDF生成に時間がかかり、ZIPが大きくなります。画像や特殊な図形の細部はブラウザ印刷版と差が出る場合があります。

2026-10-29、3セクション・5レクチャーのサンプル講座で講座一式ZIPを生成し、5個のレクチャーPDFと台本・JSON・説明文を確認しました。日本語を含むPDFを画像描画し、漢字・かなが正しく表示されることを目視確認しました。音声の単体取り込み（2秒mp3）、IndexedDB保存後の再読み込みと再生UI、種類の保持、一括割当（3秒wav）と未割当表示もブラウザで確認しました。

## AI接続について

`src/services/ai/adapter.ts` の `AiSlideAdapter` は接続口のみで、現在の実装はモックです。AIチームは上記JSON Schemaに沿うファイルを生成し、画面からインポートできます。将来APIを接続する場合、APIキーはバックエンドの環境変数で管理し、`VITE_` 付きの変数に秘密鍵を保存しないでください。
